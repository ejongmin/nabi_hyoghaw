 3-4. validate_pipeline.py  [신규 생성, 470+ lines]
------------------------------------------------------------------------

목적: 파이프라인 End-to-End 검증 (2023-01-01 ~ 2025-12-31)

6단계 검증:
  Phase 0: 데이터 로드 (유니버스, GDELT, KG, 주가, 키워드)
  Phase 1: 뉴스 탐지 — Entity linking + Risk 분류 + Severity 계산
  Phase 2: Knowledge Graph 구축 — networkx + 3개 해상 루트 노드
  Phase 3: 공급망 엣지 업데이트 감지
  Phase 4: 리스크 전파 — Shortest Path + Random Walk with Restart
  Phase 5: CAR(Cumulative Abnormal Return) 분석
  Phase 6: 리포트 저장

핵심 구현:
  - Route 노드: SUEZ, HORMUZ, MALACCA (지역 기반 연결)
  - 확장 리스크 키워드: geopolitical, logistics, natural, energy
  - Severity: clip(1.0 + norm_gs*2.5 + norm_at*1.5, 1.0, 5.0)
  - Exposure: SP = 1/(1+distance), RWR(restart=0.15, iter=50)
  - CAR: estimation[-120,-20], event windows [1,3,5,10,21]

검증 결과 (reports/validation_summary.md):
  - 총 매칭 이벤트: 13,213건
  - KG: 43 nodes, 137 edges
  - 노출 레코드: 38,840건
  - 방향성 일치율: 53.8%
  - Natural disaster CAR: -4.13% (가장 강한 신호)

 3-5. live_replay.py  [신규 생성 → 이후 전면 재작성, 530+ lines]
------------------------------------------------------------------------

[초기 버전] — articles_8y.csv (BigQuery 사전 수집) 기반 리플레이
  - 15,000건 뉴스를 메모리에 전부 로드 후 재생
  - 이벤트 전처리에 수 분 소요

[현재 버전] — GDELT v2 Raw File 실시간 다운로드 방식으로 전면 재작성

목적: 2023~2025년 GDELT v2 Raw Export 파일을 순차 다운로드하면서
      실시간 파이프라인 시뮬레이션 (마치 2023년에 수집기를 운영하는 것처럼)

주요 기능:
  1) GDELT v2 Raw File 실시간 다운로드
     - URL: http://data.gdeltproject.org/gdeltv2/{timestamp}.export.CSV.zip
     - 샘플링 간격: daily(기본) / weekly / hourly

  2) 로컬 파일 캐시
     - 경로: data/raw/gdelt/historical/
     - 재실행 시 다운로드 생략 (즉시 로드)

  3) 성능 최적화: 사전 필터
     - 전체 행에 fuzzy matching 전에 substring 사전필터 적용
     - 99%+ 행을 빠르게 제거 후 소수만 정밀 처리

  4) GLOBALEVENTID 중복 제거
     - 파일 간 동일 이벤트 재표시 방지

  5) 동적 KG 업데이트
     - 2+ 기업이 동시 등장 시 엣지 추가(NEW) 또는 강화(STRENGTHENED)
     - KG 변화를 스코어보드에 실시간 반영

  6) 터미널 출력 (ANSI 컬러)
     - [*] NEWS DETECTED    — 뉴스 탐지
     - [>>] ENTITY LINK     — 기업 매칭
     - [>>] EDGE UPDATE     — KG 엣지 변화
     - [>>] RISK PROPAGATION — 리스크 전파 (exposure bar)
     - [>>] PREDICTION vs REALITY — CAR 예측 vs 실제 결과

  7) 누적 스코어보드
     - 성공/실패 카운트 + 적중률
     - KG 통계 (static edges + new + strengthened)

사용법:
  python live_replay.py                              # 기본 (daily, 10초)
  python live_replay.py --start 2024-01-01           # 2024년부터
  python live_replay.py --interval weekly --delay 5  # 주간, 5초
  python live_replay.py --max-per-file 5             # 파일당 5개 표시
  python live_replay.py --no-cache                   # 캐시 없이

 5. 사용된 핵심 알고리즘 요약
================================================================================

[Severity 계산]
  norm_gs = clip((10 - GoldsteinScale) / 20, 0, 1)
  norm_at = clip((10 - AvgTone) / 20, 0, 1)
  severity = clip(1.0 + norm_gs * 2.5 + norm_at * 1.5, 1.0, 5.0)

[Exposure - Shortest Path]
  exposure_SP = 1 / (1 + shortest_path_distance)

[Exposure - Random Walk with Restart]
  restart_prob = 0.15, max_iter = 50
  scores(t+1) = (1 - alpha) * W * scores(t) + alpha * restart_vector

[CAR (Cumulative Abnormal Return)]
  estimation_window = [-120, -20] days
  expected_return = mean(returns in estimation_window)
  CAR[0,w] = sum(actual_return - expected_return) for days [0..w]
  event_windows = [1, 3, 5, 10, 21] days

[예측 규칙]
  부정적 이벤트 (GoldsteinScale < 0 OR risk keyword 매칭)
    → 주가 하락 예측 (CAR < 0)
  긍정적 이벤트
    → 주가 유지/상승 예측 (CAR >= 0)
